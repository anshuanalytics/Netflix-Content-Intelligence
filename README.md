# 🎬 Netflix Content Intelligence Dashboard

A professional **Power BI dashboard** built to analyze Netflix's content catalog and uncover insights related to content type, genres, countries, release years, and content distribution.
![Netflix Content Intelligence Dashboard](./netflix-dashboard-combined.png)
## 📊 Project Overview

This project transforms Netflix content data into an interactive **Power BI Content Intelligence Dashboard** designed to support data-driven analysis and business decision-making.

The dashboard provides a clear view of Netflix's content library and helps identify patterns in content growth, distribution, genres, countries, and release trends.

## 🎯 Project Objectives

* Analyze the overall Netflix content catalog
* Compare **Movies vs TV Shows**
* Understand content distribution across countries
* Identify popular genres and categories
* Analyze content trends by release year
* Explore the growth of Netflix's content library
* Build an interactive and professional business intelligence dashboard

## 🔍 Key Analysis Areas

### Content Type

Analyze the distribution between Movies and TV Shows in Netflix's catalog.

### Genre Analysis

Identify major content categories and understand which genres have the strongest representation.

### Geographic Analysis

Explore how Netflix content is distributed across different countries.

### Time Analysis

Analyze content trends based on release year to understand changes in Netflix's catalog over time.

## 💡 Business Value

The dashboard demonstrates how raw content data can be transformed into meaningful business insights using data analytics and visualization.

It can help stakeholders understand:

* Content portfolio composition
* Geographic content distribution
* Genre concentration
* Content growth patterns
* Historical release trends
